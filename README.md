# Srs. Batata - Digital Menu Web Application

Srs. Batata is a high-performance digital menu web application built with React, specifically tailored for a fast-casual restaurant chain specializing in stuffed baked potatoes. Designed with a mobile-first approach, the application delivers an intuitive e-commerce experience that allows customers to browse dynamic menus, customize ingredients, and seamlessly manage their orders. The architecture emphasizes modern front-end engineering practices, ensuring reusable component structures, responsive UI design, and optimized state management for high-traffic food delivery or table-ordering environments.

## 🚀 Features

* **Dynamic Digital Menu:** Highly responsive and visually optimized catalog showcasing product varieties, pricing, and real-time availability.
* **Interactive Customization:** Advanced product builder allowing users to choose toppings, modifiers, and custom ingredients for their stuffed potatoes.
* **Efficient Shopping Cart System:** Client-side cart logic enabling real-time calculations for quantities, pricing adjustments, and item modifications.
* **Mobile-First Responsive Design:** Seamless user experience across modern smartphones, tablets, and desktop browsers, maximizing conversion rates.

## 🛠️ Tech Stack & Architecture

* **Frontend Library:** React (Functional Components & Hooks)
* **Styling & UI:** CSS-in-JS (Styled Components) or Tailwind CSS / Responsive Grid Frameworks
* **State Management:** React Context API / Hooks for global cart and order state tracking
* **Tooling:** Vite or Create React App, and modern ESLint configurations

## 💻 Getting Started

### Prerequisites
* Node.js (v18.0.0 or higher recommended)
* npm or yarn package manager
